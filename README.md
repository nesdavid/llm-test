## HTML5 Tetris

A complete, modern retro-style Tetris game built in vanilla HTML5, CSS3, and JavaScript with Web Audio sound synthesis.

### Features
- **Guideline 7-Bag Randomizer**: Fair piece distribution without droughts.
- **Super Rotation System (SRS)**: Standard wall kicks for smooth rotations near boundaries.
- **Ghost Piece**: Real-time projection showing landing position.
- **Hold Queue & Next Queue**: Strategic piece holding and upcoming piece previews.
- **Web Audio Sound Effects**: Procedurally generated retro arcade sound effects (zero external audio file dependencies).
- **Line Clear & Particle Effects**: Visual flashes and sparks on line clears.
- **Smooth DAS (Delayed Auto Shift)**: Responsive auto-repeat movement controls.
- **High Score**: Persists locally via `localStorage`.

### How to Run
Simply open `index.html` in any modern web browser (Firefox, Chrome, Edge, Safari). No web server or installation required.

### Controls
- **Move**: `←` / `→` or `A` / `D`
- **Rotate Clockwise**: `↑` or `W` / `X`
- **Rotate Counter-Clockwise**: `Z` or `Ctrl`
- **Soft Drop**: `↓` or `S`
- **Hard Drop**: `Space`
- **Hold Piece**: `C` or `Shift`
- **Pause / Resume**: `P` or `Esc`
- **Mute / Unmute**: `M`
